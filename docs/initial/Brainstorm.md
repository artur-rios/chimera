# Chimera

## Overview

Chimera is a swiss army knife for developers. An app where you can do all sorts of useful things like, convert files and texts to base 64, generate data for testing, etc.

## Features

- Cron Parser
- Date Converter
- JSON Array to Table, CSV
- JSON to YAML Converter
- Number Base Converter
- Escape / Unescape Text
- List Comparer
- Analyzer & Utilities for text
- Text Comparer
- Base64 Image / Text Encoder and Decoder
- Certificate Encoder and Decoder
- GZIP Encoder and Decoder
- HTML Encoder and Decoder
- JWT Encoder and Decoder
- QR Code Encoder and Decoder
- URL Encoder and Decoder
- JSON, SQL, XML formatters
- Generators for Hash / Checksum, Lorem Ipsum, Password, UUID, GUID
- Credit Card generator
- Generators for all American and Brazilian documents
- Person generator
- Encode and Decode using Cyphers and Alphabets

## Technology

- Everything will be built using Flutter + Dart
- Every technology used must be on their latest stable version at the time of development

## Non-functional requirements

- It must be available on browsers, as a desktop app on windows and linux and as a CLI that runs in any terminal
- It must be fast and reliable
- It must be easy to use, and have good UI/UX
