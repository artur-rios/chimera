# UC-17 Base64 Decode Implementation Plan

> **For implementers:** execute this plan with test-driven development, record
> each task boundary in the SDD ledger, and do not publish until independent
> whole-branch review is approved.

**Goal:** Decode canonical Base64 to strict UTF-8 text or exact binary bytes,
including supported-image preview, through shared CLI, desktop, and web paths.

**Architecture:** `chimera_utilities` owns strict canonical parsing, UTF-8 text
conversion, media signature detection, and resource limits. `chimera_core` maps
typed results and failures. CLI and GUI adapters own ephemeral source access,
copy/save, localization, and presentation. Native and browser suites exercise
the same service path.

**Tech stack:** Dart `dart:convert`/`dart:typed_data`, shared Dart packages,
Flutter, `package:test`, `flutter_test`, native Flutter integration tests, and
Playwright.
