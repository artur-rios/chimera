# UC-26 QR Encode Implementation Plan

**Goal:** Generate bounded, deterministic QR PNG images across CLI, desktop,
and web from one shared local implementation.

**Branch:** `feature/uc-26-qr-encode`

## Task 1: Shared encoder

- [ ] Add failing utility tests for defaults, all error-correction levels,
  Unicode, colors, margins, exact dimensions, deterministic PNG output,
  capacity, malformed Unicode, image-size limits, and resource failures.
- [ ] Add the pinned pure-Dart QR and image dependencies.
- [ ] Implement `QrEncoder`, typed options/results/exceptions, and export it.
- [ ] Pass the utility suite and commit `feat: add local QR encoder`.

## Task 2: Core operation

- [ ] Add failing service tests for success metadata and validation/resource
  failure mappings.
- [ ] Implement `QrEncodeService` and export it.
- [ ] Pass the core suite and commit `feat: add QR encode service`.

## Task 3: CLI adapter

- [ ] Add failing functional tests for argument, stdin, and file input; option
  validation; localized human summaries; stable JSON; capacity errors; and
  transactional PNG output failures.
- [ ] Add `chimera qr encode` and localized usage/errors.
- [ ] Pass l10n and CLI suites and commit `feat: expose QR encoding in cli`.

## Task 4: GUI adapter

- [ ] Add failing widget tests for generation, exact-byte preview/save,
  controls, file and clipboard input, localization, error handling, focus, and
  semantics.
- [ ] Add `/qr/encode`, navigation, dependency injection, preview, and
  localized English/Brazilian Portuguese messages.
- [ ] Pass GUI tests and commit `feat: add QR encode page`.

## Task 5: Supported targets and review

- [ ] Extend native integration and browser/Safari smoke coverage with QR
  encode success and validation scenarios.
- [ ] Update accessibility evidence and technology-stack resolution.
- [ ] Run formatting, analysis, focused tests, and the exact full gate.
- [ ] Request an independent branch review and resolve every finding.
- [ ] Move UC-26 to Testing, push the branch, open the PR, wait for required
  checks, squash-merge, verify issue/project closure, and delete the branch.
